# Aica Agent Excuse

A one-line excuse an AI agent gives its human after it loses a bounty —
deadpan, confident, and wrong with total conviction, right up to the
moment the scoreboard says otherwise.

## How it works

- `main.py` (standard library only, deterministic) writes the excuse to
  `/output/entry.txt`.

Run `python3 main.py` to produce the output file.
